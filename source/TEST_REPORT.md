## Limits and ownership

The uploaded plan contains assignment metadata, not27 complete questions. No measured owner before/after27-question success rate is available. Owner Chrome is unattached. The graph counterexample, unseen generated families, isolated browser UI and exact math proofs establish specific corrected boundaries, not universal course coverage.

Model runtime/weights are not bundled. Official weight downloads returned403, so actual local-model inference is unverified. The model can only authorize autoentry where a separate bounded formal directive/task binding and exact verifier succeed. Arbitrary word interpretation and graph drawing remain review-only.

Actual Tesseract transcription is tested and can misread powers; the explicit owner PNG workflow stays UNVERIFIED and never supplies automatic answers. Generic scalar/MathQuill fields cannot safely express every multi/no/all solution set; those require a known choice/widget format or remain review.

Stop prevents future actions and cancels pending extension work; already entered text is preserved. Unknown submission outcomes are never blindly retried. No actual course credit, owner playback credit, private application-state access or universal solver claim is made. Project Sovereign, RADAR, MasterChess and prior frozen releases were not modified.

For local diagnosis after helper installation, use `helper/.venv/bin/python helper/diagnose.py` so it sees the pinned dependencies. Before installation, `python3 helper/diagnose.py` provides hardware information only.
